# Task 3 - Book REST API

A simple REST API built using Node.js and Express.js to manage a list of books.

## Features

- GET all books
- POST a new book
- PUT/update a book
- DELETE a book

## Technologies Used

- Node.js
- Express.js
- Postman

## API Endpoints

GET /books  
POST /books  
PUT /books/:id  
DELETE /books/:id

## How to Run

```bash
npm install
node server.js
